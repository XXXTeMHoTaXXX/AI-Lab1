Лабораторная работа №1
Системы искусственного интеллекта. Экспертная система с прямой цепочкой рассуждений.
В качестве предметной области выбрал совместимость комплектующих ПК. Программа проверяет сокет процессора и материнской платы, а также тип оперативной памяти. Используются платформы AM4, AM5, LGA1700 и память DDR4, DDR5. Конкретные модели комплектующих и версии BIOS не учитываются.
Файлы
- main.py — программа и консольное меню.
- rules.txt — база правил в формате ЕСЛИ ... ТО ....
- facts.txt — начальные данные.
Запуск
Нужен Python 3. Дополнительные библиотеки не используются. Все три файла должны находиться в одной папке.
python main.py
Использование
В меню можно запустить проверку, посмотреть факты и правила, отредактировать правила или ввести свои начальные данные. Изменения правил сохраняются в rules.txt.
Для ввода данных нужно выбрать пункт 5 и указать факты через запятую:
процессор=AM5, плата=AM5_DDR5, озу=DDR5
Затем выбрать пункт 1. Для этого примера результат будет совместимость=да.
Пример с разными сокетами:
процессор=AM5, плата=AM4_DDR4, озу=DDR4
Результат: совместимость=нет.
Если данных недостаточно, программа предложит добавить новый факт, например озу=DDR5. Пустой ввод завершает вывод.
Начальные данные, введённые через меню, действуют до закрытия программы. Для сохранения нужно изменить facts.txt.
Как работает вывод
Программа перебирает правила и проверяет их условия по известным фактам. Если все условия выполнены, результат добавляется в рабочую базу. Проверка повторяется, пока появляются новые факты. После этого программа показывает заключение или запрашивает новые сведения.
