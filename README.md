# ЛР 1. Подбор ПК по бюджету

Пишем бюджет в рублях, выбираем производителя процессора и задачу. Программа подбирает конкретный процессор, видеокарту, плату, ОЗУ, SSD, блок питания, кулер и корпус. Показывает цены, сумму и остаток бюджета.

Это учебная база. Цены в prices.txt заданы для проверки лабораторной и не являются текущими ценами магазинов. В бюджет входит системный блок, без монитора, периферии, лицензии ОС и услуг сборки.

## Запуск

Распакуй папку целиком. Открой терминал в папке, где лежит main.py.

```text
python main.py
```

Нажми 1. Введи бюджет, например 60000. Потом выбери производителя: 1 = AMD, 2 = Intel. Задача: 1 = офис, 2 = игры. Ответы 60000, 1, 2 дают игровой вариант AMD за 55500 учебных рублей.

Номер из списка нужно вводить цифрой. Бюджет тоже вводится цифрами, можно с пробелом: 60 000. Пустой ответ означает, что новых сведений нет, подбор завершается.

## Файлы

- main.py: вопросы, механизм прямого вывода и проверка стоимости.
- rules.txt: 53 правила выбора комплектующих.
- prices.txt: модель=цена, цена в рублях. Здесь можно поменять стоимость.
- facts.txt: исходные данные для пункта 6.

## Как работает подбор

В базе заданы три уровня: эконом, средний, высокий. Для каждого уровня программа запускает одни и те же правила с выбранным производителем и задачей, получает компоненты и складывает их цены. Выбирается самый высокий доступный уровень. Более высокий уровень определяется порядком в списке levels, а не ценой отдельной детали. Если даже эконом не помещается, система показывает минимальную сумму и недостающие деньги. Изменение цен автоматически меняет доступный уровень, в коде нет фиксированных денежных порогов.

Рассуждение строится по цепочке: задача -> приоритет; производитель + приоритет + уровень -> процессор; процессор -> сокет -> плата -> тип памяти; приоритет + уровень -> ОЗУ, GPU и SSD; GPU -> блок питания. Для офисного варианта используются процессоры со встроенной графикой. Наличие подходящих правил и цен проверяется до выдачи сборки.

Здесь не перебираются все комплектующие рынка. Система выбирает лучший доступный уровень из ограниченной учебной базы. Это не доказательство максимального FPS за каждый рубль.

## Меню

1. Ответить на вопросы и подобрать ПК.
2. Показать рабочие факты последнего вывода.
3. Показать правила.
4. Добавить, изменить или удалить правило с сохранением.
5. Задать стартовые факты вручную.
6. Подобрать ПК по стартовым фактам из файла или пункта 5.
0. Выйти.

Пример для пункта 5:

```text
бюджет=80000, производитель=Intel, задача=игры
```

После него нажми 6. Для сохранения стартовых данных навсегда измени facts.txt. После ручного изменения rules.txt или prices.txt перезапусти программу. При добавлении новой модели в правила добавь её цену в prices.txt и проверь совместимость.

## Быстро разобраться в коде

get_fact разделяет объект и значение по знаку =. get_rule отделяет условия от результата. run проверяет все условия каждого правила и добавляет новые факты, пока что-то меняется. details выключает печать для предварительных расчётов, ask выключает запросы при проверке кандидата. configure запускает правила для трёх уровней, считает стоимость и оставляет последний доступный уровень. get_total складывает цены восьми компонентов. choose_value превращает номер ответа в факт. main показывает меню.

На защите: «Знания о подборе находятся в rules.txt. Механизм прямого вывода добавляет результаты правил в рабочую базу, и они запускают следующие правила. Дополнительно программа оценивает стоимость выведенных вариантов по prices.txt и выбирает наиболее высокий уровень в пределах бюджета».

## Проверки

- 60000, AMD, игры: Ryzen 5 5500, RX 6600, 16 ГБ, SSD 1 ТБ, всего 55500.
- 80000, AMD, игры: Ryzen 5 5600, RTX 4060, 32 ГБ, SSD 1 ТБ, всего 70500.
- 100000, Intel, игры: Core i5-12400F, RTX 5060 Ti 16 ГБ, 32 ГБ, SSD 2 ТБ, всего 99000.
- 40000, AMD, офис: Ryzen 5 5600G, встроенная Radeon Graphics, 16 ГБ, SSD 1 ТБ, всего 38500.
- 20000, AMD, игры: сборка не выдаётся, минимальная сумма 55500, не хватает 35500.

Проверены 12 сочетаний производителя, задачи и уровня; бюджеты на границах стоимости; изменение цен; перестановка правил; ошибочный ввод.

## Совместимость и источники

В учебной базе используются платы DDR4 для AM4 и LGA1700. Для AMD может потребоваться обновление BIOS. Модель видеокарты указана по GPU: перед покупкой конкретной карты нужно проверить её размеры, разъёмы питания и рекомендованный БП. Для корпуса MATREXX 40 допустима длина карты до 320 мм. Конкретное исполнение ОЗУ, комплектация вентиляторов и поставка кулера также проверяются отдельно.
